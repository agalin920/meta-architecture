# Proven skills

Skills that helped in one system and then still helped when tried in a second
(`playbook.md` § The playbook rule, § How a lesson travels). New systems copy
them into `.claude/skills/`; existing systems take them as trials, never by sync.

One folder per skill, `<name>/SKILL.md`, beside a `RECORD.md`: the home system,
its verdict, the second system's trial and verdict, and the dates.

Only general mechanism: no repo, product, ticket format, credential path or
anything personal. This repo is public.

None yet. The first can arrive no earlier than 44 days after a system's first
skill lands (14 days to a verdict, plus 30 held in a second system).
