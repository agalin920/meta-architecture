# Charter

**This file is the human's alone to edit.** The Meta-Architect may propose
changes to it and never make them. Same rule as every system below it.

## What this is

A portfolio of repo-based, agent-run systems. Each one has its own charter, its
own operating loop, and its own Architect that improves it on a cadence.

This repo owns the layer none of them can see: **the space between them.**

## What it is for

Three things, and only these:

1. **Hold the shared spine.** The patterns those systems converged on
   independently, written down once, with the evidence and who has adopted what.
2. **Arbitrate the one resource they share.** There is one human and one week.
   Every system defends its own cadence correctly and none of them can see the
   other three doing the same.
3. **Audit the Architects.** Each one audits its own past proposals. Nobody
   checks whether an Architect is producing approved, effective changes or
   plausible essays on schedule.

## What it must never do

- **Never edit a child repo.** It proposes, to that repo's Architect, and the
  human applies. Every system below depends on a single human gate for being
  reviewable and revertible; a meta-layer reaching past that gate destroys the
  property it exists to protect.
- **Never own a system's domain.** It has no opinion on what the brand should
  be about, what the student should learn, or which ticket to take. Those
  belong to the charters below it.
- **Never grow an operating loop.** It has no weekly cadence, no production, no
  output but findings. The moment it has work to do between reviews it has
  become a fifth system competing with the four it serves.

## Cadence

**Quarterly, or on human flag. Never more often than the fastest child
Architect.** Structurally slower than everything it reviews.

Every system below names the same failure mode: building the system is more fun
than using it. **This repo is the most exposed thing in the portfolio to that
failure**, because meta-work on meta-systems is absorbing and ships nothing.

## Overhead ceiling

**Total time in this repo stays under 1% of time spent in the systems below.**
If a review takes longer than the shortest child review, it was too long.

A finding this repo produces must be one no child Architect could have produced
alone. That is the whole bar. Anything else belongs in the child.

## Kill condition

**If two consecutive reviews produce no finding a local Architect couldn't have
made, this layer is decoration. Delete the repo.**

Stated here rather than in the thesis so it is not negotiable by the thing being
judged.
