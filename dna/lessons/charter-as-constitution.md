# Charter as constitution

**Status:** `founding` (ruling 1; labelled, not re-proved)

**Lesson.** One file states what the system is for and its hard lines, and no
agent may edit it. A self-modifying system needs one fixed point, or its
improvement loop will in time optimise the definition of success itself.

**Evidence**
- Present in every system in the lineage, but review 001 counted it as **one
  derivation** (the founding set was built by one person in two days):
  `archive/meta/architect-log.md:3225`, `:3243`.
- It gives agents an authority to appeal to: brand-system's Writer refuses a
  brief by citing the charter, not an opinion:
  `archive/patterns/charter-as-constitution.md:21-23`.
- The gate held where it was tested: resale-desk staged a charter amendment as
  a PROPOSED file and only the human applied it:
  `resale-desk: docs/project-log.md:102-104` (harvest R-10).
- No measured change of outcome is on record. The status rests on ruling 1
  (`REDESIGN.md:94-96`), not on a number.

**Where it failed / limits**
- **Split across files** it has no single answer: zesty-eng-team's contract
  lived in two docs plus a settings allowlist:
  `archive/patterns/charter-as-constitution.md:42-44`.
- **Words are not a lock.** The new kernel puts the charter and the settings
  file behind deny rules that must be tested by an edit attempt
  (`REDESIGN.md:188-197`), because `Write(...)` denies were found inert:
  `archive/meta/architect-log.md:989-994`.
- **Premises go stale** when someone outside owns them; the human still owns
  the risk decision: `archive/meta/architect-log.md:2957-2982`.
- The record around it can drift: resale-desk's handoff still said "NOT
  applied" after the human applied the amendment:
  `resale-desk: HANDOFF.md:28-30` *(uncommitted)*.
- A charter with no clause that can rule against the human's momentary
  preference is decoration: `archive/patterns/charter-as-constitution.md:47-50`.
