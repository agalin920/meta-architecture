# Architect on cadence

**Status:** `retired` (ruling 4, 2026-10-28: rituals are optional).

**Lesson.** A meta-agent that improves the system on a cadence (every N
sessions, every retro), proposing and never applying, did not run when the
cadence depended on a human starting it. The goal survives; the ritual does not.

**Evidence**
- **Five of nine Architects never ran**, and an Architect that does not run
  writes nothing about not running: `archive/meta/architect-log.md:3376-3380`.
- **Retros ran only when Andres typed `/retro`.** zesty-eng-team's three
  retros in the window were all Director-invoked; `/retro` was human-invoked
  in every system: `archive/meta/architect-log.md:3337`, `:3351-3353`.
- **the-debrief printed "eleven slices overdue"** in its own boot state and
  never ran one: `archive/meta/architect-log.md:3342`, `:3349-3351`.
- engage went 69 days between retros; personal-university's review due at
  session 10 ran at 15; brand-system's never ran in 80 days:
  `archive/meta/architect-log.md:3292`, `:3344-3345`.

**Where it failed / limits (and what was kept)**
- **When it did run, it worked:** every Architect that ran graded itself
  accurately and harshly (`archive/meta/architect-log.md:3374-3376`;
  `REDESIGN.md:57-58`). Its best parts moved into the continuous loop:
  [grade-previous-cycle](grade-previous-cycle.md),
  [mandatory-cuts](mandatory-cuts.md), precise-diff proposals, written
  withdrawals.
- Its "propose, never apply" gate is retired separately:
  [human-approves-self-changes](human-approves-self-changes.md).
- The warning it carried stays true: if meta-work outnumbers the work, that
  is the failure announcing itself (personal-university's 2:3 ratio:
  `personal-university: meta/architect-log.md:870-878`).

**Origin.** Convergent founding, carried over from an earlier project of the
same person (zesty-eng-team's decision log). Replaced by kernel 3, the loop.
